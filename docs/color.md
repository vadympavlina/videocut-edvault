# Колір у Videocut

Сторінка «Колір» (перемикач угорі або Alt+2) працює як у DaVinci Resolve: кожен кліп має свій граф вузлів. Повернутися на монтаж: Alt+1.

## Як це влаштовано
- Дані: `clip.cg` у проєкті (чистий JSON): `nodes` (id, type, x, y, off, p) і `links` (from, to, port). Скасування, повторення, автозбереження й файл `.evproj` працюють без змін.
- Рендер: `videocut-app/js/color.js`. Граф компілюється в ланцюжок проходів WebGL2 (проміжні текстури RGBA16F, якщо відеокарта вміє, інакше RGBA8). Перегляд і експорт викликають одну й ту саму функцію `applyGraph` з `drawClipFrame`, тож результат збігається.
- Тільки для перегляду: `COLOR_VIEW` (роздільник «До / Після», маска HSL, кнопка «Оригінал»). В експорті, у знімку кадру й у збереженому PNG ці режими вимкнені.
- Інтерфейс: `color-ui.js` (сторінка, інспектор, редактор вузлів, рецепти), `scopes.js` (осцилографи).

## Вузли
| Вузол | Що робить |
| --- | --- |
| Вхід, Вихід | Початок і кінець графа |
| Первинна | Колеса тіней / півтонів / світел / зсуву, експозиція, контраст, світла й тіні, температура, відтінок, насиченість |
| Криві | Яскравість, R, G, B: монотонна кубічна інтерполяція |
| HSL | Виділяє колір за відтінком, насиченістю й яскравістю (з піпеткою) і змінює лише його |
| LUT | Файл `.cube` (3D-текстура на GPU) |
| Ефекти | Віньєтка, зерно, сяйво, вицвілі чорні |
| Змішати | Дві гілки: звичайний, додати, множення, екран, накладання, м'яке світло, різниця |

## Маски, авто-корекція, спільний граф
- Маска (коло, прямокутник, градієнт) є на будь-якому коригувальному вузлі: Первинна, Криві, HSL, LUT, Ефекти. Рамка над кадром: тягніть, щоб перемістити, маркер у куті змінює розмір, поворот і м'якість у повзунках. Це поле `node.mask`.
- «Авто-корекція кадру» (Первинна) підбирає експозицію, контраст і баланс білого за поточним кадром.
- «До всіх кліпів» копіює граф вибраного кліпа в усі інші.

## Вихід, впорядкування, компактний вигляд
- Вузол «Вихід» має «Силу корекції» (0–100%, ключується): змішує результат з оригіналом, щоб послабити готовий рецепт.
- «Впорядкувати» розкладає вузли зліва направо за глибиною графа без накладань.
- На невисоких екранах (до 820 px) колеса йдуть в один ряд по чотири, панель графа ужата, список рецептів підлаштовується під ширину.

## Ключові кадри
- Ромбик біля повзунка (або біля колеса) додає ключовий кадр у поточному місці кліпа. Далі будь-яка зміна цього параметра в іншому місці сама дописує ключ. Між ключами значення змінюється лінійно, поза ними тримається. Лінійність потрібна, щоб розріз і обрізання кліпа не змінювали форму анімації: ключі розділяються точно.
- Анімуються всі числові параметри вузлів і маски: експозиція, колеса, насиченість, віньєтка, положення й розмір маски тощо. Криві й перемикачі не анімуються.
- Смужка під кадром показує ключі вибраного вузла, по ній можна клікати й тягнути; стрілки ‹ › переходять до попереднього й наступного ключа.
- Розріз, вирізання діапазону, стоп-кадр, обрізання лівого краю перетягуванням, стик (Shift) і зміна швидкості кліпа зберігають анімацію на тих самих місцях вмісту: ключі ділються, зсуваються або масштабуються. Те саме тепер робиться й з ключами руху (масштаб, позиція).
- Дані: `node.kf = { 'p.exp': [[секунди від початку кліпа, значення], …] }`. Рендер (перегляд, експорт) однаковий: `animatedGraph(cg, t)`.

## Перевірка
- `npm test` — модель, ремонт графа, математика на CPU (`tests/videocut-color.test.mjs`).
- `npm run test:color` — шейдери проти еталона на CPU (`tests/videocut-color-e2e.mjs`) і сторінка «Колір» (`tests/videocut-color-ui-e2e.mjs`).
- `npm run audit:a11y` включає сторінку «Колір».

## Обмеження
- Потрібен WebGL2. Без нього сторінка відкривається, але корекція не застосовується (з'являється повідомлення).
- Колір працює лише для основної доріжки (кліпи). Відео-накладення поки без графа.
- Один граф на кліп. Групові графи й відстеження масок за рухом не реалізовані.
- Колірний простір sRGB / Rec.709, без HDR.
