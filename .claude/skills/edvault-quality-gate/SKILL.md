# Контроль якості · videocut-edvault

Статичний відеоредактор на чистому JS (ES-модулі, без збирання): канвас 2D, WebGL-хромакей, mediabunny для експорту.
Інтерфейс українською, без емодзі, звернення без роду. Тема за замовчуванням темна, перемикач лишається
(правила темного режиму з `CLAUDE.md` обов'язкові).

## Макет
Панелі стикуються впритул, тонкі розділювачі, без закруглених карток і тіней («острівців»): верхня смуга, ліворуч бібліотека,
у центрі перегляд з керуванням відтворенням під ним, праворуч властивості, внизу таймлайн на всю ширину, рядок стану.
Ширина бічних панелей змінюється розділювачами (`dock.js`). Нових «острівців» не додавати.

## 1. Перед змінами
- Прочитай `videocut-app/js/player.js` (перемотування, подвійна буферизація), якщо чіпаєш відтворення чи таймлайн.
- Перед редизайном спершу покажи варіанти (знімки), потім роби обраний.

## 2. Після змін, обов'язково
| Що | Команда |
| --- | --- |
| Модульні тести | `npm test` |
| Браузерні тести (потрібен ffmpeg) | `PLAYWRIGHT_MODULE=… npm run test:e2e` |
| Список модулів для попереднього завантаження | `npm run build`, перевірка `npm run audit:build` |
| Доступність (axe, дві теми: `THEME=light`) | `npm run audit:a11y` |
| Клавіатура, фокус, цілі дотику | `npm run audit:keyboard` |
| Швидкість: імпорт 1080p, 60 розрізів, водіння курсора, відтворення | `npm run audit:perf` |
| Стрес: швидкі play/pause, 60 кліпів, undo/redo, експорт, пам'ять | `npm run audit:stress` |

Бюджети: готовність до роботи до 3 с, p95 кадру під час водіння до 80 мс, довгих задач понад 400 мс немає, відтворення
просувається в реальному часі. Тест із розрізами й перемотуванням (22-24 кроки e2e) не повинен миготіти.

## 3. Правила
- Кнопка-значок обов'язково має `data-tip` (з нього `a11y.js` робить `aria-label`).
- Нові поля форми кладуть у `.field` з `<label>`; решту підписів дає `a11y.js`.
- Нові модалки відкривай через `openModal` (пастка фокусу, повернення фокусу, Esc).
- Дані проєкту, що приходять ззовні (файл, база), проходять `repairProject` у `state.js`.
- Шрифти лише з `fonts/` (без Google Fonts), скрипти без вбудованого коду (діє CSP).
- Пошкоджене збереження не повинно ламати запуск: копія в `project_broken`, редактор стартує порожнім.

## 4. Звіт
Коротко: що змінено, які перевірки пройдено, що не вдалося перевірити.
